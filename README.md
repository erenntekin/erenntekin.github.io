# erenntekin.github.io

Eren Tekin's personal portfolio. Built with Next.js (App Router), TypeScript, Tailwind CSS, and Framer Motion, exported statically and hosted on GitHub Pages.

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

Static output goes to `out/` (`output: "export"` in `next.config.ts`).
